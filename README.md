# Isha Patel — Exclusive VIP Access

A single-page landing card for Isha Patel's official VIP Telegram channel. It shows the channel's profile, member stats, and a 15-second countdown, then sends visitors to the Telegram invite link automatically. Visitors can also tap "Join Telegram Now" to go straight there.

## Technologies

- Plain HTML, CSS, and vanilla JavaScript in one file (`index.html`), with no build step
- Google Fonts (Cinzel, Plus Jakarta Sans)
- Hosted on Netlify as a static site

## Running locally

Open `index.html` in a browser, or run `netlify dev --port 8889` to serve it locally.
